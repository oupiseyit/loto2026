# Admin Role — Figma Screens

**Figma Page:** `Admin`  
**File:** https://www.figma.com/design/w1QlWIADCGWRd1m1ZcVgHU/LOTT0999

| Frame | Description |
|---|---|
| `Admin / 01-Login` | Full-screen crimson login with floating decorations |
| `Admin / 02-Home` | Bet entry — sees all sessions, full numpad, submit |
| `Admin / 03-Record` | All staff records, all tabs, win/lose totals |
| `Admin / 04-Result` | **Can enter & edit results** (input fields enabled) |
| `Admin / 05-Setting` | Printer + **Commission section visible** |
| `Admin / 06-Account` | Total sales across all staff + user management panel |
| `Admin / 07-Report` | Full report — all staff, no filter restriction |

## Key Differences from Other Roles
- **Result:** input fields enabled (can type winning numbers)
- **Setting:** Commission row visible (Default / Custom radio)
- **Account:** shows total across all users + Add User button
- **Report:** staff dropdown shows all staff, no scope filter
