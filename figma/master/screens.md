# Master Role — Figma Screens

**Figma Page:** `Master`  
**File:** https://www.figma.com/design/w1QlWIADCGWRd1m1ZcVgHU/LOTT0999

| Frame | Description |
|---|---|
| `Master / 01-Login` | Same login screen as admin |
| `Master / 02-Home` | Bet entry — same controls, scoped to own bets |
| `Master / 03-Record` | Own staff records only (created_by filter) |
| `Master / 04-Result` | Read-only — result cells disabled, no save button |
| `Master / 05-Setting` | Printer settings only — Commission row **hidden** |
| `Master / 06-Account` | Own staff sales + **Create Staff** button visible |
| `Master / 07-Report` | Staff dropdown scoped to own staff only |

## Key Differences from Admin
- **Result:** all inputs disabled, no Save button
- **Setting:** Commission row not rendered
- **Account:** shows own staff sales; Add Staff button (not Add User)
- **Report:** staff dropdown only shows master's own staff
